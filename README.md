# Rahul Kumar — QA Engineer Portfolio

Responsive React + Vite portfolio in a white, charcoal and warm-brown palette, with light animations.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
1. Extract the ZIP.
2. Open the extracted `rahul-qa-portfolio` folder in VS Code.
3. Open Terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Before publishing — important
1. Replace the `RK` photo placeholder in `src/main.jsx` with your own profile photo (or keep the placeholder).
2. Replace generic LinkedIn and GitHub URLs in `src/main.jsx` with your actual profile URLs.
3. Add verified official app-store/live website links for IFSTA and StayVista. The project visuals are illustrative CSS mockups, not real app screenshots.
4. Confirm all project claims, tools, download counts, dates and wording before publishing.
5. Contact form uses `mailto:` and opens the visitor's email application; it does not send/store submissions on a server.
6. Resume PDF is included in `public/Rahul_Kumar_QA.pdf`. Replace it when your resume is updated.
